# MCA201P-AS08 — Lab Sheet 07

Two Python answers arranged like the provided `java3.zip` example (question-numbered source files).

- **Q1.py** — Customer segmentation with K-Means and hierarchical clustering.
- **Q2.py** — News article clustering with TF-IDF, K-Means and hierarchical clustering.

## Run

Install Python 3.11+ and run from this directory:

```bash
pip install -r requirements.txt
python Q1.py
python Q2.py
```

Sample synthetic datasets are in `data/`. Generated charts and evaluation tables are in `outputs/`. Scripts regenerate those outputs. The examples are for coursework demonstrations, not real-world model validation.
